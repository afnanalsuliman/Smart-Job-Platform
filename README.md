# Smart Job Platform 💼

A web-based job management platform built using Flask, SQLite, HTML, CSS, and Python.

## Features

* Add new job listings
* Edit existing jobs
* Delete jobs
* Store jobs in SQLite database
* Dynamic salary visualization using Matplotlib
* Experience-level salary analysis
* Clean and responsive user interface

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Pandas
* Matplotlib
* Git & GitHub
